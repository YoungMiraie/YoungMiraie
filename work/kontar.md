# Kontar — commercial CRM and applied AI

[Back to profile](../README.md)

Kontar is one of the projects where I work with backend services, integrations and applied AI together. It is a commercial CRM connecting conversations, pipelines, goals and agent workflows.

## My work

I work on the connection between the commercial process and the software: application behavior, API integrations, backend rules and agent tools. This includes maintaining the relationship between user actions, persisted data and background processing.

## Engineering focus

- A Next.js interface backed by a NestJS API.
- PostgreSQL data modeling through Prisma.
- Redis and BullMQ for asynchronous processing.
- Conversation and pipeline workflows with API integrations.
- OpenAI-based agents with tools tied to application workflows.
- Validation of application changes and controlled releases.

## Technical foundation

TypeScript, Next.js, NestJS, PostgreSQL, Prisma, Redis, BullMQ, OpenAI API and Docker.

## Project context

Developed in the context of my work at LVX Digital, with ongoing development and validation of specific features. This overview does not imply that every integration or agent capability is active or independently validated. It excludes customer information, operational configuration and private code.
