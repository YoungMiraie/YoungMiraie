# Polaris — internal operations platform

[Back to profile](../README.md)

One part of my work is taking operational processes and turning them into software people can use every day. Polaris is an example: an internal platform connecting client operations, project management, communication and finance.

## My work

I work across the interface, business rules, integrations and serverless backend. The part I find interesting is connecting the details: how a client moves through a process, how a delivery is recorded and how those events should appear in reports.

## Engineering focus

- Client and project boards with operational states.
- Financial workflows and reporting rules.
- API integrations connecting communication and business data.
- React interfaces supported by Firestore, Authentication, Storage and Cloud Functions.
- Targeted checks for business rules and changes to the deployed application.

## Technical foundation

React, JavaScript, Vite, Tailwind CSS, Firebase, Firestore, Cloud Functions and REST APIs.

## Project context

Developed in the context of my work at LVX Digital. Source code, customer records and infrastructure configuration are private. This overview does not publish a demo, a deployment address or a claim about measured business results.
